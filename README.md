# markcidr

Mark URLs and cidr query parts with stable normalization.

**Site:** https://theworker02.github.io/markcidr/

## Install / run

```bash
git clone https://github.com/theworker02/markcidr.git
cd markcidr
node src/cli.js
node --test
```
